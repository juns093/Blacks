[1] 게임 한 줄 요약
----------------------------------------------------------------
기억을 잃은 판사가 정체불명의 남자(???)와 러시안 룰렛을 하며 계속 죽는다.
죽을 때마다 과거의 "물건" 하나가 떠오르고, 그 물건을 만지면 그 시절의 기억
(회상)으로 들어간다. 기억 4개를 다 되찾으면 자신이 돈을 받고 임상시험 사망
사건을 덮은 판사였다는 것, 그리고 ???가 그 피해자의 아버지라는 것이 밝혀진다.
마지막에는 조작 없는 진짜 러시안 룰렛으로 결판을 낸다.

장르: 1인칭 호러 / 미스터리 / 추리. 분위기: 어둡고 불안하고, 점점 죄책감이 드러난다.

■ 주인공 (플레이어)

  - 과거: Drail 제약회사의 임상시험 사망 사건 재판을 맡았고,
    사장 트레일에게 돈을 받고 사건을 덮었다.
    (실험 기록 조작, 사망 원인 조작, 증거 인멸, 무죄 판결)
  - 대사에는 이름표가 붙지 않는다. 속마음은 ( ) 괄호로 쓴 경우가 있다.

■ ??? (Who, 딜러)
  - 테이블 맞은편에서 러시안 룰렛을 강요하는 남자. 정체가 밝혀지기 전까지 이름표는 "???".

[3] 게임 흐름 (순서대로) — 각 단계에서 나오는 대사 칸
----------------------------------------------------------------
※ 대사창은 화면 아래 한 줄씩 타자 치듯 나오고, 약 2초 뒤 자동으로 다음 줄로 넘어간다.

(1) 시작
    주인공이 테이블 앞에서 깨어남 → [Intro_Main]
    → 탄 장전 연출(초록=빈 탄, 빨강=실탄이 테이블에 보임) → 러시안 룰렛 시작(조작된 판)

(2) 1번째 죽음 (룰렛에서 총에 맞음, 피격 연출)
    → [Player_Death_First]  (테이블 화면 위에서. 이때는 물건이 안 나온다. 고통만)
    → 다시 장전 → 룰렛

(3) 2번째 죽음
    → 눈을 감은 검은 화면에 "물건 1: 망치(판사봉)"가 떠오름
    → 그 검은 화면 위에서 [Player_Death_Second]
    → 플레이어가 물건을 클릭 → 기억 1 (회상 영상, 타임라인)
         · 영상 도중 [Item1]  (트레일이 판사를 찾아와 재판을 조용히 끝내 달라고 부탁)
    → 영상이 끝나고 테이블로 돌아와서 [Item_Use_First]
    → 다시 룰렛

(4) 3번째 죽음
    → 검은 화면: 망치 + "물건 2: 혈액 팩"
    → [Player_Death_Third]
    → 클릭 → 기억 2 (직접 걸어 다니는 탐색 구간, 어두운 병원, 손전등 F키)
         · 탐색 안내 문구: [탐색2_안내]
         · 병동에서 열쇠를 줍는다 → [열쇠_문구]
         · 열쇠 근처 침대에서 구울(괴물)이 눈앞에 튀어나오는 점프 스퀘어(대사 없음, 비명 소리)
         · 증거 3개를 찾아서 [E]로 읽고 [F]로 조작한다 → [증거1] [증거2] [증거3]
           (주인공이 과거에 직접 했던 증거 인멸을 플레이어가 그대로 재현하는 장면)
         · 3개를 다 조작하면 → [탐색2_안내]의 "증거 완료" 문구
         · 동쪽 문으로 가면 "여기구나..." → 암전 → 회상 영상
         · 영상 도중 [Item2]  (짐승의 발 → 구울을 목격)
    → 테이블로 돌아와서 [Item_Use_Second]
    → 다시 룰렛

(5) 4번째 죽음
    → 검은 화면: 망치 + 혈액 팩 + "물건 3: 바이러스(약)"
    → [Player_Death_Fourth]
    → 클릭 → 기억 3 (회상 영상, 연구실)
         · 영상 도중 [Item3]  (과학자 드레일을 만남. 괴물을 만든 걸 자랑하고, 사망자를 개의치 않음)
    → [Item_Use_Third]
    → 다시 룰렛

(6) 5번째 죽음
    → 검은 화면: 물건 4개 모두 ("물건 4: 구급상자")
    → [Player_Death_Fifth]
    → 클릭 → 기억 4 (회상 영상 + 탐색)
         · 영상 도중 [Item4]  (재판이 끝나고 트레일이 "보수는 구급상자에 넣어 뒀다"고 함)
         · 영상이 멈추고 거리에서 직접 걸어 다님: 구급상자 줍기 → E키 차 키 경적으로 차 찾기
           → 차에 타고 떠남 (문 소리, 시동, 암전)
           안내 문구: [탐색4_안내]
         · 영상이 이어서 끝남
    → [Item_Use_Forth]  (모든 기억이 돌아옴: 주인공의 자백 + ???의 정체와 사연 + "마지막 승부")
    → [Final_Rules]      (지금까지 판이 조작이었다는 폭로 + 러시안 룰렛 규칙 첫 설명)
    → 마지막 승부 (조작 없는 진짜 룰렛)
         · 지면: 마지막 승부만 다시 시작 (지금은 대사 없음)
         · 이기면: 엔딩 씬(StoryScene)으로 넘어감 (별도 장면, 이 문서 범위 밖)

물건과 기억의 상징
  - 망치  = 판사봉. 판결 / 뒷거래의 시작
  - 혈액 팩 = 병원. 피해자와 괴물
  - 바이러스 = 약, 연구실. 드레일의 실험
  - 구급상자 = 뇌물이 든 상자. 사건을 덮은 대가

[5] 대사 쓰는 규칙 (기술적인 제약)
----------------------------------------------------------------
- 한 줄 = 대사창에 한 번에 뜨는 문장. 한 줄은 짧게(한글 약 35자 이내 권장).
- 말하는 사람 표시: "???: ", "트레일: ", "드레일: " 처럼 앞에 이름과 콜론.
  주인공 대사는 이름표 없이 그냥 쓴다. 속마음은 ( ) 괄호.
- 줄 수는 자유. 단, 회상 영상 도중 대사([Item1]~[Item4])는 영상 길이가 정해져 있어서
  지금 줄 수와 비슷하게 맞춰 주세요(너무 길면 영상이 끝난 뒤에도 대사가 남는다).
- [Player_Death_Second]~[Player_Death_Fifth]는 검은 화면에 물건이 떠 있는 상태에서 나온다.
  "눈을 감았는데 뭔가 보인다" 같은 연출과 맞춰 주세요.
- 아직 정체를 모르는 동안 ???는 이름표가 "???"다. (정체가 밝혀진 뒤에도 지금은 ???로 되어 있음.
  바꾸고 싶으면 이름을 정해 주세요.)
- 증거 문서: 제목 / 원래 내용 / 조작 후 내용 / 조작 방식(고쳐 쓰기 or 찢어 없애기) /
  조작 직후 주인공 속마음 한 줄.
  "고쳐 쓰기"는 원래 글자가 한 자씩 검게 지워진 뒤 조작한 내용이 새로 적힌다.
  "찢어 없애기"는 종이가 찢겨 사라지고 "조작 후 내용" 칸의 한 줄만 남는다.
- 안내 문구는 화면 아래 작은 글씨. {0}/{1}은 개수로 바뀌니 그대로 두세요.
