----------------------------------------------------------------
 1-1. 사건의 흐름
----------------------------------------------------------------
 드레일이 다이어트 약이라고 속여 괴물을 만드는 실험을 함
 → 참가자들이 잇따라 실종, 경찰이 수사를 시작
 → 트레일이 판사에게 증거 인멸 + 무죄 선고를 청탁 (뒷거래)
 → 판사는 이익에 눈이 멀어 망설임 없이 그대로 실행
 → 딸을 잃은 ???가 복수를 다짐, 판사를 납치해 벅샷 테이블로 데려옴

 실탄 안에는 Psilo-D(환각제)가 들어 있다.
 판사가 맞으면 죽지 않고, 환각 속에서 자기가 한 일을 보게 된다.
 (마지막 5판의 탄에는 약이 없다. 진짜다.)

 2. 판 구조
----------------------------------------------------------------
 [PROLOGUE] 깨어남 → "러시안 룰렛." → 1판 시작

 1~3판 : ??? 와의 판 (게임에 익숙해지고 이야기를 이해하는 구간)
   - ???를 쏴 죽이면 → ENDING 1 (아무것도 기억하지 못한 채 걸어 나감)
     ???는 복수를 끝내기 전엔 확실한 빈 탄일 때만 자기를 쏜다.
   - 내가 맞으면(환각탄): 화면이 일그러지고 어지러운 환각이 아이템을 누를 때까지 계속됨
     → 화면 위쪽 띠에 아이템이 차례로 뜸
     → 아이템을 누르면 아이템 대사 → 그 기억 속으로 (직접 걸어 다니는 탐색)
     → 기억이 끝나면 테이블로 돌아와 추리 질문 → 다음 판 대사

   1판에서 죽음 → [휴대폰]  → 기억 1: 지하철
   2판에서 죽음 → [혈액]    → 기억 2: 병원
                 [약]      → 기억 3: 병원2 (드레일의 연구실)
   3판에서 죽음 → [구급상자] → 기억 4: 거리
                 → 문이 열리고 트레일이 맞은편에 앉는다. ???는 옆에 서서 지켜본다.

 4판 : 트레일 과의 판
   - 트레일을 죽이면 → ENDING 2 (???: "가자... 난 할 일이 남았어.")
   - 트레일에게 죽으면 → 환각(법정, 돈 봉투) → "내가 그랬구나."
     → 새로운 아이템 [17번의 사진과 기록] → 암전, 총성 한 발
     → 밝아지면 트레일은 테이블 옆에 엎어진 시체, ???가 다시 맞은편에.

 5판 : ??? 와의 마지막 판 (옆에 트레일의 시체)
   - "처음부터 이럴 생각이었어?" / "???: 내 딸이야. 19살이었어." / "???: 네 목숨."
   - ???에게 죽으면 → "???: 끝났어." → ENDING : 사망
   - ???를 죽이면 → 흩어진 문서들을 확인
       · 추리 질문을 한 번에 맞힌 수가 4개 이상 → ENDING : 자수
       · 모자라면 → ENDING : 괴물 (드레일의 목소리)

 상대가 죽을 때는 책상에 머리를 박으며 쓰러진다.


----------------------------------------------------------------
 3. 기억(탐색) 구간
----------------------------------------------------------------
 기억 1: 지하철 (휴대폰)
   승강장을 둘러봄(선택 단서: 트레일의 명함, 신문, 재판 일정 메모)
   → 걷다가 전화벨 → [E] 전화 받기 → 통화 장면(트레일)
   → 계단으로 역 밖에 나감 → 역 앞 거리 끝의 공중화장실 맨 안쪽 칸에서 사건 자료
   → 중요한 줄에 밑줄 긋기. 2개를 그으면 칸막이 문을 쾅쾅 두드리는 소리
     "관리인: 아저씨! 화장실 마감합니다. 나오셔야 해요!" → "잠, 잠시만요...!" → 나머지 2개
   → METRO 표지판으로 돌아가기 → 영상 이어서 → 추리 질문

 기억 2: 병원 (혈액)
   선택 단서(간호사 쪽지, Drail 공문)
   → 동쪽 병동(양문을 열고 들어가는 새 병동, 병실 8개)에서 Drail 실험실 열쇠 찾기
   → 증거 3개를 찾아 조작/파기 → 잠긴 방 → 마지막 장소 → 영상 → 추리 질문

 기억 3: 병원2 (약)
   선택 단서(실험 일지, 피험자 명단, 드레일 메모) → 키카드 → 잠긴 문 → 드레일의 연구실

 기억 4: 거리 (구급상자)
   사람들 눈을 피해 [구급상자(안에 든 돈)]와 [차 키]를 찾는다.
   - Shift로 달릴 수 있다. 가까이서 뛰면 행인이 발소리를 듣고 돌아본다.
   - 행인들은 집으로 걸어가는 퇴근길 사람들(NavMesh). 집에 들어가면 사라졌다가 다시 나타난다.
   - 들키면 "행인: 저기요. / 거기서 뭐 해요?" → 변명을 고른다 (50% 확률로 통과)
     실패하면 처음 자리로 돌아가고 모은 것도 원래 자리로.
   → E로 경적을 울려 차 찾기 → 차에 타면 시동 소리 + 엔진 소리로 떠남


----------------------------------------------------------------
 4. 사망 연출
----------------------------------------------------------------
 - 피격 타임라인 대신: 총성 → 화면이 확 일그러지고 색이 빠짐 + 귀 울림(삐-)
 - 검은 화면 없이, 화면 위쪽 띠에 지금까지의 아이템이 차례로 놓이고 새 아이템이 나타난다.
 - 4판(트레일에게 죽음)에서만 짧은 환각 대사가 나온다.
